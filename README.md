# blindtype — пошаговая публикация на GitHub Pages

## 1. Что загружать
Загрузите **содержимое папки deploy** в корень репозитория, то есть файлы:
`index.html`, `styles.css`, `app.js`, `manifest.json`, `sw.js`, `icon.svg`,
`.nojekyll`, `README.md`. Не загружайте саму папку `deploy` как вложенную.

Файл `index.html` самодостаточный: CSS и JS встроены в него, поэтому тёмный
интерфейс отобразится корректно, даже если внешние файлы не загрузились.

## 2. Создание репозитория
1. Войдите в GitHub → **New repository**.
2. Repository name: например `blindtype` (латиницей, без пробелов).
3. Visibility: **Public** (для бесплатного GitHub Pages).
4. Не ставьте галочки «Add a README», «.gitignore», «license» — папка пустая.
5. **Create repository**.

## 3. Загрузка файлов через сайт (без Git)
1. На странице репозитория нажмите **Add file → Upload files**.
2. Перетащите туда все файлы из папки `deploy`.
3. Нажмите **Commit changes**.

## 4. Альтернатива — через Git
```
git clone https://github.com/ВАС/blindtype.git
cd blindtype
# скопируйте содержимое deploy сюда
git add .
git commit -m "blindtype PWA"
git push
```

## 5. Включение GitHub Pages
1. Репозиторий → **Settings** → **Pages**.
2. Build and deployment → Source: **Deploy from a branch**.
3. Branch: **main** (или `master`), папка: **/(root)** → **Save**.
4. Через 1–2 минуты откройте
   `https://ВАС.github.io/blindtype/` — обязательно со слешем на конце.

## 6. Проверка приложения
1. Откроется экран **АВТОРИЗАЦИЯ**.
2. Перейдите на вкладку **РЕГИСТРАЦИЯ**, введите логин (от 3 символов)
   и пароль (от 6 символов), повторите пароль, нажмите **СОЗДАТЬ АККАУНТ**.
3. Пройдите занятие, обновите страницу — вы останетесь в аккаунте,
   история и достижения сохранятся.
4. Проверьте **ВЫЙТИ ИЗ АККАУНТА** в разделе «Настройки» и повторный вход.

## 7. Если интерфейс выглядит как обычный белый текст
- Нажмите **Ctrl+F5** (жёсткая перезагрузка).
- DevTools → **Application** → **Service Workers** → **Unregister**, обновите.
- DevTools → **Network**: проверьте, что страница открылась по `https://`,
  а не `file://`, и что нет 404 у `index.html`.
- Убедитесь, что загружен файл именно из папки `deploy`, а не из исходной
  папки проекта, и что он называется точно `index.html`.

## 8. Как работают данные
- База IndexedDB `blindtype_db` хранит учётные записи и профили.
- Пароль не хранится открытым текстом: PBKDF2, 100000 итераций, SHA-256, соль 16 байт.
- Токен в localStorage позволяет входить автоматически после перезагрузки.
- Данные остаются на устройстве пользователя; синхронизации между
  устройствами нет, при очистке данных браузера профиль удаляется.

## Важно
Не открывайте страницу через `file://` — service worker и база данных
могут работать некорректно. Только HTTP/HTTPS, GitHub Pages подходит.
